# EditPlus 京都観光コンシェルジュ — デザインプレビュー

パスワード保護された静的プレビュー。閲覧にはパスワードが必要です。

- URL: https://takumin-2525.github.io/editplus-kyoto-mock/
- 中身は staticrypt で暗号化済み（パスワードなしでは閲覧不可）。最初のページで「このブラウザで記憶する」を付けたまま開くと、以降のページは入力なしで見られます
- ホスティング: GitHub Pages

## このプレビューで見られるもの・見られないもの

開発中のWordPressサイトを、ある時点でそのまま静的に書き出したものです。

| 見られる | 見られない（サーバーが要るため） |
|---|---|
| トップ・特集記事・スポット（約310件）・エリア／ジャンル一覧・ホテル・現在地ページ・6言語のUI | 巡り方診断（AIコース提案）・現在地からの検索・キーワード検索・ホテル名の候補表示・管理画面 |

動くものは検証環境（kankou-concierge-test.com）で確認してください。
